VS Code Interactive Sessions with uv

Set up a lightning-fast Python workflow inside standard .py files using the uv package manager.

  • No need for .ipynb notebooks: Work directly with Python scripts.
  • Standard Library Sample: Explore code execution step-by-step using built-in modules like pathlib and json.
  • Blazing Fast: Powered entirely by the modern uv package manager.

The Code Sample

Use code cells (#%%) in your standard .py file to run snippets interactively:

#%%
from pathlib import Path
import json

# Define path and sample data
current_dir = Path.cwd()
print(f"Working Directory: {current_dir}")

sample_data = {
    "project": "VS Code Interactive with uv",
    "status": "Active",
    "items": [10, 20, 30, 40, 50]
}

total_sum = sum(sample_data["items"])
print(f"Total Sum: {total_sum}")

Automatic Locking with uv add

When you run a command like:

uv add requests

uv does two things automatically:

  • Adds the package to your pyproject.toml configuration file.
  • Automatically creates or updates your uv.lock file, pinning exact dependency versions.

Syncing & Managing Dependencies in VS Code

  • Sync Environments: Run uv sync to align your local virtual environment (.venv) precisely with your lock file.
  • VS Code Integration: Select your uv-managed virtual environment as your Jupyter Kernel.
  • Instant Reload: If you add packages, simply restart your Jupyter Interactive kernel in VS Code to load them right away.
