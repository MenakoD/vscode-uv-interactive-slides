If you prefer not to continuously open and close PowerShell or Command Prompt to test scripts while building a Python project, an interactive Jupyter session inside VS Code is an efficient solution. It lets you execute and observe your code evolving line by line directly inside standard Python files, without needing to switch your entire workflow to standalone Jupyter notebooks (.ipynb). Explore this step-by-step workflow guide below using the uv package manager.

VS Code Interactive Sessions with uv

Set up a lightning-fast Python workflow inside standard .py files using the uv package manager.

  • No separate notebooks needed: Keep your exploratory workflow directly inside standard Python scripts.
  • Standard Library Example: Execute code step-by-step using built-in modules like pathlib and json.
  • Modern Tooling: Lightning fast environment management powered by uv.

The Python Code Sample

Use cell markers (#%%) in your script to execute sections interactively:

#%%
from pathlib import Path
import json

# Define path and sample data structure
current_dir = Path.cwd()
print(f"Working Directory: {current_dir}")

sample_data = {
    "project": "VS Code Interactive with uv",
    "status": "Active",
    "items": [10, 20, 30, 40, 50]
}

total_sum = sum(sample_data["items"])
print(f"Total Sum: {total_sum}")

Automatic Locking with uv add

When you run a package installation command in your terminal:

uv add requests

uv handles two tasks automatically under the hood:

  • Adds the dependency directly to your pyproject.toml file.
  • Creates or updates your uv.lock file to pin precise version states.

Syncing & Managing Dependencies in VS Code

  • Environment Syncing: Run uv sync to make sure your local .venv matches your lock file configuration precisely.
  • Jupyter Kernel Integration: Select your uv virtual environment as your active VS Code Jupyter Kernel.
  • Seamless Workflow: Add packages and instantly refresh your interactive kernel to bring changes live.
